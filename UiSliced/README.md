# UiSliced: per-state PNGs from sleek_fantasy_controls_v1

Generated by `slice_sheets.py` from `S:\AI\Game\Game Assets\ui\sleek_fantasy_controls_v1` (originals untouched). This folder is **outside `Assets/`**, so Unity does not import it until you copy the folders you want into `Assets/`.

Re-run after replacing a sheet: `python slice_sheets.py [source_dir]`.

## Contents

- `sliced/<sheet>/<sheet>__<state>.png`: 63 states. **Every state of one control is scaled so its solid body has the same width as the first state, and all states share one canvas with the body centered on the same pivot**, so Sprite Swap neither shifts nor resizes the control (glows extend past the body). Scale changes are small (about 0 to 8%; Heart pressed is the largest at 7.5%, window-mode icons about 3 to 4%). Icon sheets are only trimmed and centered, not rescaled.
- `preview/<sheet>.png`: contact sheet of each sheet on a dark checkerboard.
- `manifest.json`: per state `source_box`, `canvas`, `scale_applied`, `body` (solid body size after scaling), `pivot` (body center in the canvas, in pixels from the top-left), `glow_margin`.

## Using them in Unity

- Import as **Sprite (Single)**, Mesh Type Full Rect, no compression artifacts (use High Quality or uncompressed for the large frames).
- Button: Transition = Sprite Swap with the normal, pressed, selected/active and disabled sprites. Set **Image size from the manifest `body`** (not `canvas`), because selected and ready states include soft glow outside the body.
- The art is large (primary button body about 497x130 px). Set the Image to the target dp size and let Unity scale it down; check it at the real phone size.
- **9-slice** (`panel_frame`, `panel_header`, `chip_resource`, `bar_progress` frame and fill): set Sprite Editor borders. Starting values to tune by eye: frame about 220 px on every side (its corners are asymmetric, ornate at top-left and bottom-right, so use the larger value), header and chip about 160 px left and right and 40 px top and bottom, progress bar about 130 px left and right. Test at the largest and smallest sizes you need.
- The **header and chip are very wide** (about 1950x200 and 1850x475). Scale them down; do not use them at native size.

## Known art issues (from review)

- Selected primary and the Heart **ready** state have strong, slightly ragged glows. Prefer to crop or replace those glows with a separate additive glow sprite and pulse it in Unity.
- Panel interiors keep a faint texture; verify it does not tile visibly when stretched.
- Nothing here has been imported or tested in Unity yet.
